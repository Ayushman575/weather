# 🌤️ Weather App

A modern, responsive weather web application built with HTML, CSS, and Vanilla JavaScript using the OpenWeatherMap API.

## ✨ Features

- **Live Weather Data**: Real-time temperature, weather conditions, humidity, wind speed, and atmospheric pressure.
- **5-Day Weather Forecast**: Displays daily weather forecasts with high and low temperatures.
- **City Search**: Search for any city worldwide with instant weather results.
- **Responsive & Modern UI**: Sleek glassmorphism card design with dynamic weather icons and backdrop blur.
- **Keyboard Friendly**: Press <kbd>Enter</kbd> to search quickly.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Ayushman575/weather.git
   ```
2. Open `index.html` in your browser, or launch it with Live Server.

## 🛠️ Built With

- **HTML5 & CSS3** (Vanilla CSS, Glassmorphism, Google Fonts, Material Symbols)
- **Vanilla JavaScript** (Fetch API, Async/Await)
- **OpenWeatherMap API**
